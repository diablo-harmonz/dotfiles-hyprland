# zsh

Copies of Manjaro's shell setup (`manjaro-zsh-config` 0.26, MIT license, see
`LICENSE.manjaro-zsh-config`), so the same shell works on plain Arch where that package
does not exist. `~/.zshrc` uses the system files when they exist (Manjaro) and these
copies otherwise. They need the Arch packages `zsh-autosuggestions`,
`zsh-syntax-highlighting`, `zsh-history-substring-search`, `zsh-completions` and
`zsh-theme-powerlevel10k` (installed by `setup/setup-arch.sh`).
